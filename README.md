# Mahoraga

Mahoraga is a desktop assistant that is designed around the idea that an assistant should do as much as possible and adapt to the issues you may face. By using an AI layer with a tool system, computer controls, memory, task management, browser interaction, and hardware connectivity, the project is designed to grow into a general-purpose AI system that can understand an objective, execute actions, use tools, and adapt (hence the name Mahoraga) when an approach fails. 
There are two options: For those above 18, you can use a free Gemini API key from Google AI Studio, which will allow full usage of Mahoraga's tools. Otherwise, you can get an API key from HCAI using a model known as Qwen, and it will only provide more basic functions.
Requirements:
macOS on Apple Silicon (M1 or newer); Google Chrome for browser features if using a Gemini API Key. A Gemini API key or an HCAI API key. 
Installation: Download Mahoraga-v1.0.1-macOS-arm64.zip from the latest release and extract it. Open Mahoraga.app. 
On first launch, Mahoraga will ask for your Gemini API key. This release contains the compiled macOS application rather than only the Python source code.
