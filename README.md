# Mahoraga

Mahoraga is an AI desktop assistant designed around the idea that an assistant should do more than generate text. Instead of functioning purely as a chatbot, Mahoraga combines an AI layer with a modular tool system, persistent memory, task management, browser interaction, computer controls, hardware connectivity, and a native desktop interface. The project is designed to grow into a general-purpose personal AI system capable of understanding an objective, selecting appropriate tools, executing actions, observing results, and adapting when an approach fails. It has numerous useful tools ingrained into it, which have numerous practical applications while working on projects. There are two options: For those above 18, you can get a free gemini api from Google AI studio, which will allow usage of the numerous tools Mahoraga provides. Otherwise, you will be using a model known as Qwen, and it will only provide chat opportunities with HCAI support.

The latest stable release of Mahoraga is available on the GitHub Releases page.

Mahoraga is a desktop AI assistant for macOS with conversational AI, persistent memory, file search and reading, application and folder launching, web browsing, tool execution, and extensible device support. Requirements

macOS on Apple Silicon (M1 or newer); Google Chrome for browser features if using a Gemini API Key. A Gemini API key or an HCAI API key. Installation: Download Mahoraga-v1.0.1-macOS-arm64.zip from the latest release and extract it. Open Mahoraga.app. On first launch, Mahoraga will ask for your Gemini API key. The key is stored locally in your macOS Application Support directory and is not included with the application. This release contains the compiled macOS application rather than only the Python source code.
